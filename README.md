# Groq 連續聽寫

在瀏覽器裡連續錄音，自動分段送到 Groq 轉錄，再修正成台灣正體中文。系統會偵測幻聽並標示可疑處，方便人工審閱，最後整理成附「待確認清單」的筆記。

**線上使用：** https://daouz.github.io/groq-dictation/

## 流程

1. **錄音與切段**：說話停頓時自動切段（預設 8–40 秒）。用「有聲秒數」判斷，靜音段只保存不送出，可以減少幻聽。
2. **轉錄**：可選 `whisper-large-v3-turbo` 或 `whisper-large-v3`。使用 `verbose_json`，取得每句的信心、靜音機率與重複率。
3. **幻聽偵測**：
   - 自動濾除片尾套語（「請不吝點讚訂閱」「字幕由…提供」等）。
   - 偵測重複循環、低信心句、字數異常，以及詞彙表被當成內容的情況。
   - 可疑段落會自動換另一個模型重辨識，再比對兩版的相似度。差異大，或其中一個模型沒聽到內容，就標成高風險。
4. **修正**：用 `gpt-oss-120b` 或 `gpt-oss-20b` 批次校對：轉正體、修同音錯字、加全形標點。模型會以 JSON 回報「疑似幻聽／語意不通／疑似錯字／數字或名詞存疑」，可疑處保留原文，不會被自行抹平。
5. **人工審閱**（逐段審閱分頁）：
   - 篩選「待審閱」段落，在審閱面板播放原音，可變速、循環。
   - 對照 turbo 和 large-v3 兩版原始結果，逐條採用建議、刪除或保留原文。
   - 支援修改紀錄還原、全文尋找與取代（取代的詞可加入詞彙表），也可指定用 large-v3 重辨識。
6. **整理全文**：分塊整理成筆記，包含標題、摘要、分節內容（附來源段號）、重點與待辦，以及**待確認清單**（語意不通、疑似幻聽、建議重新辨識的段落）。清單中的段號點一下就能跳到該段審閱，也可以把建議重新辨識的段落一鍵改用 large-v3 重跑。

## 保存與壓縮

- 每段原始音檔都會保存：Opus 單聲道，16／24／32 kbps，約 7–15 MB／小時。Opus 對語音已經是很有效率的格式，不需要再壓縮。
- 上傳的長音檔會保留原檔，在瀏覽器內解碼並依靜音切段，送出時才轉成 16 kHz WAV，所以不受 25 MB 上限影響。
- 會向瀏覽器要求永久保存，並顯示目前用量。
- **ZIP 匯出／匯入**：ZIP 內含所有音檔、`session.json`、合併稿、逐段校對與整理稿，可以在另一台裝置匯入後繼續編輯。
- Safari 會清除 7 天沒開啟的網站資料。建議把本頁「加入主畫面」，並定期匯出 ZIP。

## Groq 額度（免費方案）

- 免費方案的 gpt-oss 限額是每分鐘 8K token、每天 200K token；Whisper 每小時 7,200 秒音訊。
- 設定裡選「免費方案」時，會自動縮小每次送出的量。
- 遇到額度上限時，佇列會暫停並自動等待，錄音與存檔不受影響。
- 大量使用時，建議修正改用 20b（額度和 120b 分開計算），或升級開發者方案。
