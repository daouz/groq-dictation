# Groq 連續聽寫

在瀏覽器裡連續錄音，自動分段送到 Groq 轉錄，再修正成台灣正體中文，最後整理成結構化筆記。

**線上使用：** https://daouz.github.io/groq-dictation/

## 流程

1. 錄音時偵測說話停頓，自動切段（預設 8–40 秒），錄音不會中斷。
2. 每段用 `whisper-large-v3-turbo` 轉錄。
3. 用 `openai/gpt-oss-120b` 或 `openai/gpt-oss-20b` 校正：轉成正體字、修正同音錯字、加上全形標點。
4. 轉錄與修正是兩條獨立佇列並行處理，遇到限流會自動重試，結果一律依錄音順序排列。
5. 「整理全文」把已完成的內容整理成固定格式的筆記：標題、摘要、分節內容、重點與待辦、名詞，可下載成 Markdown。

## 使用方式

- 第一次開啟時，在「設定」貼上你的 Groq API key（從 console.groq.com 取得）。金鑰只存在你自己的瀏覽器 localStorage，不會上傳到這個 repo 或任何其他地方。
- 音檔與文字存在瀏覽器的 IndexedDB 裡。重新整理後，未完成的段落會自動繼續處理。
- 錄音時請讓分頁保持在前景。手機鎖屏會中斷麥克風。
- 支援 Chrome、Edge、Safari（iOS 16.4 以上）。
